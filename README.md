# صفحة الحجز المسبق — بيت الخالة

صفحة بتشرح الحضانة والاشتراكات، وفيها فورم حجز مسبق. كل طلب بينزل في Google Sheet، والحضانة بتكلم الأهل وتسجّل الطفل يدويًا في البرنامج لما يجوا.

**الصفحة متنشرة على GitHub Pages** (برّه جوجل)، و**Google Apps Script** شغلته بس إنه يستقبل الحجز ويكتبه في الشيت. ده بيمنع رسالة "يتعذر فتح الملف" اللي جوجل بيطلعها لأي حد فاتح أكتر من حساب جوجل في نفس المتصفح.

```
الأهل ← صفحة GitHub Pages ← (POST من غير حسابات جوجل) ← Apps Script doPost ← الشيت
```

## الملفات

| الملف | فيه إيه |
|---|---|
| `Code.gs` | الإعدادات (`CONFIG`: الأسعار، المواعيد، التليفون، العنوان، `bookingUrl`) + حفظ الطلبات + تجهيز الشيت |
| `Index.html` | الصفحة نفسها (قالب واحد بيشتغل في المكانين) |
| `Logo.html` | اللوجو (مدمج جوه الملف) |
| `appsscript.json` | إعدادات مشروع Apps Script (توقيت القاهرة، Web app متاح للكل) |
| `docs/index.html` | **النسخة المتنشرة على GitHub Pages**، وبتتعمل من `node tools/build.mjs` (ما تعدلهاش بإيدك) |
| `tools/build.mjs` | بيبني `docs/index.html` من `Index.html` و`Logo.html` و`CONFIG` |
| `tools/serve.mjs` | معاينة على الجهاز: `node tools/build.mjs --preview` وبعدها `node tools/serve.mjs` ← http://127.0.0.1:5199 (الحجز وهمي ومش بيتحفظ) |

## 1) Apps Script (الشيت + استقبال الحجوزات)

1. افتح الشيت ← **Extensions ← Apps Script**.
2. الصق `Code.gs`. واعمل من ➕ **HTML** ملف اسمه `Index` (الصق فيه `Index.html`) وملف اسمه `Logo` (الصق فيه `Logo.html`). ومن ⚙️ **Project Settings** علّم على "Show appsscript.json" والصق `appsscript.json`.
3. اختار **`setup`** ودوس **Run**، ووافق على الصلاحيات. لو ظهرلك "Google hasn't verified this app": دوس **Advanced ← Go to … ← Allow**.
4. **Deploy ← New deployment ← Web app**، وExecute as: **Me**، وWho has access: **Anyone**. انسخ رابط `/exec`.
   - لو فيه deployment قبل كده: **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy**. كده الرابط مش بيتغير.
5. حط رابط `/exec` في `CONFIG.bookingUrl` في `Code.gs` اللي في المشروع هنا.

## 2) GitHub Pages (الصفحة اللي الأهل بيفتحوها)

1. شغّل `node tools/build.mjs`، وده بيحدّث `docs/index.html`.
2. اعمل repo على GitHub (لازم يكون **Public** علشان Pages ببلاش)، وارفع فولدر المشروع ده كله.
3. في الـ repo: **Settings ← Pages ← Build and deployment**، وSource: **Deploy from a branch**، وBranch: **main**، والفولدر: **/docs** ← **Save**.
4. بعد دقيقة أو اتنين هيظهر الرابط: `https://USERNAME.github.io/REPO/`. ده الرابط اللي تنشره للأهل.
5. جرّب حجز واحد وتأكد إنه نزل في تابة **الحجوزات**.

## لما تعدّل حاجة

| عدّلت إيه | تعمل إيه |
|---|---|
| الأسعار، الباقات، التليفون، العنوان (`CONFIG`) أو شكل الصفحة | عدّل في المشروع هنا ← `node tools/build.mjs` ← ارفع على GitHub. **والصق `Code.gs` كمان في Apps Script** ← Run `setup` (علشان تابة الملخص تتحدث) ← New version |
| حفظ الحجوزات بس (`submitBooking`) | الصق `Code.gs` في Apps Script ← New version |

**الأسعار في `CONFIG` منسوخة من البرنامج يدويًا.** لو المالكة غيّرت سعر في البرنامج، عدّلوه هنا كمان.

## الشيت

لو السكربت مفتوح من الشيت نفسه، هيظهر في الشيت قايمة اسمها **بيت الخالة ← تجهيز الشيت (الورق والأعمدة)**. القايمة دي بتعمل تابتين أو بتصلّحهم: **الحجوزات** و**ملخص**، وعلى الحجوزات اللي موجودة. تقدر تدوس عليها أكتر من مرة، ومش بتمسح أي حجز. ولو حد مسح تابة الحجوزات بالغلط، أول حجز جديد بيرجّعها لوحده.

كل طلب = صف فيه: رقم الطلب (`BK-0001`...)، الوقت، ولي الأمر، التليفون، الطفل، سنه بالشهور، الباقة، البداية المتوقعة، المصدر، ملاحظات الأهل، **رقم مكرر؟**، **الحالة** (جديد / اتواصلنا / اتسجل / مش مهتم، ولونها بيتغير) و**ملاحظات الحضانة**. آخر عمودين للموظفات يحدّثوهم بإيديهم.

تابة **ملخص** فيها معادلات بتتحدث لوحدها: إجمالي الطلبات، الأرقام المكررة، والعدد حسب الحالة والباقة و"عرفونا منين".

لما الحضانة تفتح: الأعمدة دي نفس بيانات شاشة **الاستفسارات** في البرنامج، فتسجّلوها هناك وتكملوا المتابعة من البرنامج.

## أمان وخصوصية

- الصفحة بتكتب في الشيت بس، ومحدش من الزوار يقدر يقرا الطلبات. الـ repo العام فيه الكود والأسعار بس، ومفيهوش أي بيانات أهل.
- الحجز بيتبعت من غير حسابات جوجل الزائر (`credentials: 'omit'`).
- فيه حماية من الطلبات الآلية (حقل مخفي) ومن تكرار نفس الطلب خلال 10 دقايق.
- أي نص بيبدأ بـ `=` أو `+` بيتشال أوله علشان ما يتحولش لمعادلة في الشيت.
- البيانات دي بيانات أطفال: ما تشاركوش الشيت غير مع اللي محتاجه، وامسحوا الطلبات القديمة اللي مالهاش لازمة بعد التسجيل.
